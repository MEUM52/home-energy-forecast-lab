# 05 — Deep Learning (İsteğe Bağlı)

<badge>Opsiyonel modül</badge>

Bu modül, temel proje akışını tamamlamak için gerekli değildir. Python, veri analizi ve temel makine öğrenmesi modüllerini tamamlayan öğrenciler için ileri seviye ek çalışma alanıdır.

## Kapsam

- Derin öğrenme kavramlarına giriş
- Zaman serisi tahmininde derin öğrenmenin ne zaman anlamlı olabileceğini araştırma
- Daha karmaşık modellerin Baseline ve mevcut makine öğrenmesi yöntemlerine karşı adil değerlendirilmesi

## Önemli

- Bu modülün tamamlanması 06_AI_Application uygulamasını çalıştırmak için ön koşul değildir.
- Ana proje akışında şu anda derin öğrenme modeli bulunmamaktadır.
- Bu klasör, isteğe bağlı öğrenme içeriği için yer tutucudur; mevcut Baseline, Linear Regression veya Random Forest modellerini değiştirmez.
- Derin öğrenme denemesi yapılırsa aynı kronolojik veri ayrımı ve test verisini model seçimi için kullanmama ilkeleri korunmalıdır.
